# One45 Schedule Wrangler Glossary

Controlled vocabulary for One45 Schedule Wrangler, associated scripts, and documentation. Use these terms verbatim.

---

## Tool and Output

| Term | Definition | Do Not Use |
| :--- | :--- | :--- |
| **Partner** | An institution that sends curriculum schedules to be imported into One45. | *client, customer, school* |
| **Batch** | The complete set of Partner Workbooks sent for a single term, processed together (e.g., all Course uploads for Spring 2026). | *run, job, upload* |
| **Check Run** | Executing the Wrangler against a Batch containing exactly one Partner Workbook to validate and normalize it. Produces a Portfolio Tab for each Portfolio found, or one Course Tab when the file has no Portfolio and holds a single Course. | *single-file mode* |
| **Combine Run** | Executing the Wrangler against a Batch of two or more Partner Workbooks. Produces Portfolio Tabs consolidated across all workbooks, or one Course Tab when the whole Batch is a single Course with no Portfolio. | *merge, multi-file mode* |
| **One45 Schedule Wrangler** | The application (`create-master-schedule-workbook.py` and `wrangler-gui.py`) that normalizes and converts a Batch into a Batch Import. | *One45 Wrangler, batchlore, Schedule Master Workbook* |
| **Batch Import** | The artifact generated by One45 Schedule Wrangler: a workbook containing Portfolio Tabs (or a single Course Tab) plus a Change Log Tab; or, when using `--file-per-tab`, a directory containing one such workbook per Portfolio. | *Master Schedule, master workbook, output file* |
| **Flagged Cell** | A cell in the Batch Import highlighted in red indicating a data contradiction requiring human intervention before import. Restricted to records where `End Time <= Start Time`. | *error, warning* |
| **Portfolio Tab** | A tab in the Batch Import containing all rows assigned to one Portfolio. Named after the Portfolio. Contains no `portfolio` column (presence triggers rejection by the One45 importer). | *portfolio sheet, course tab* |
| **Course Tab** | A tab in the Batch Import named after a Course. Used strictly when a Batch contains exactly one unique Course and zero Portfolio designations (Portfolio is selected manually in One45 at import time). Multiple Courses without a Portfolio never produce Course Tabs. | *course sheet* |
| **File Tab** | A tab in the Batch Import named after a source Partner Workbook, containing unassigned rows from that file. Generated only when someone chooses "Give each its own tab" in the window or passes `--unassigned-file-tabs`. | *unassigned tab, review tab* |
| **Change Log Tab** | The final tab in every generated Batch Import workbook, with one row per automated transformation (skipped sheets, header renames, dropped or added columns, date/time coercion, filled Portfolios, File Tabs, and flagged cells). Excluded from One45 import operations. | *audit log, diff* |

## Input Structure

| Term | Definition | Do Not Use |
| :--- | :--- | :--- |
| **Partner Workbook** | An individual `.xlsx` file received from a Partner, typically covering one Course. | *course file, source file* |
| **Schedule Sheet** | The sheet in a Partner Workbook containing scheduled Sections to import. Commonly labeled "Schedule Upload" by Partners. | *schedule tab* |
| **Mapping Sheet** | A sheet in a Partner Workbook mapping Sessions to objectives or competencies. Commonly labeled "Mapping Upload" by Partners. Ignored by One45 Schedule Wrangler. | *Curriculum Sheet, objectives tab* |

---

## One45 Curriculum Hierarchy

| Term | Definition | Do Not Use |
| :--- | :--- | :--- |
| **Portfolio** | The top-level One45 curriculum container targeted during import, scoped to a specific term and cohort (e.g., `Summer 2026, MED 4`). Every row on a Portfolio Tab imports into this container. | — |
| **Course** | A discrete curriculum unit inside a Portfolio (e.g., `Intro to Biology`). | — |
| **Subcourse** | An optional child subdivision of a Course used by some Partners for blocks or weeks (e.g., `Intro to Biology > Week 1`). | *block, module* |
| **Session** | An individual educational activity within a Course (e.g., a lecture, lab, or seminar). | *event* |
| **Section** | A specific scheduled instance of a Session, distinguished by date, time, or student cohort. | *occurrence, class* |
